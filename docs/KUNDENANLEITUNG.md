# Anleitung für die Garage Klausner – Website selbst pflegen

Sie brauchen nur einen Browser. Alles Redaktionelle – Texte, Bilder, Öffnungszeiten, Adressen,
Menü – ändern Sie im **Studio** unter `https://<Ihre-Website>/studio`. Anmeldung mit der E-Mail-Adresse,
die eingeladen wurde (kein Passwort merken nötig – Sie erhalten einen Anmeldelink per E-Mail).

## Aufbau

Links im Studio stehen drei Bereiche:

- **Seiten** – jede Seite der Website (Start, Werkstätten, Familienbetrieb, Kontakt, Impressum, Datenschutz).
- **Werkstätten** – Adresse, Telefon, E-Mail und Öffnungszeiten je Standort. Werden überall automatisch eingeblendet.
- **Website-Einstellungen** – Name, Logo, Haupt-Telefon, Menü, Fusszeile, Suchmaschinen-Texte.

## Text ändern

1. Bereich **Seiten** → Seite anklicken.
2. Unter «Bausteine» den passenden Baustein aufklappen (z. B. «Text neben Bild»).
3. Text ändern. Fett/Kursiv/Link über die kleine Leiste im Textfeld.
4. Unten rechts **Veröffentlichen** – nach wenigen Sekunden ist die Änderung online.

Solange Sie nicht auf «Veröffentlichen» klicken, ist die Änderung nur ein Entwurf und für Besucher unsichtbar.

## Vorschau vor dem Veröffentlichen

Oben im Studio auf **Vorschau** klicken. Rechts sehen Sie die Website mit Ihrem Entwurf; ein Klick auf einen
Text springt direkt zum passenden Feld. Was Ihnen gefällt: **Veröffentlichen**. Was nicht: **Änderungen verwerfen**.

## Bild austauschen

1. Im Baustein auf das Bild → **Ersetzen** (oder Bild hineinziehen). JPG oder PNG, gern gross (mindestens 1600 Pixel breit).
2. **Bildbeschreibung** ausfüllen (Pflicht): kurz sagen, was zu sehen ist. Das wird Menschen mit Sehbehinderung vorgelesen.
3. Veröffentlichen.

## Öffnungszeiten, Telefon, Adresse

Bereich **Werkstätten** → Standort → Felder anpassen → Veröffentlichen. Die Fusszeile, die Werkstatt-Karten
und das Kontaktformular übernehmen die Änderung automatisch.

## Preise, Termine, Aktionen

Dafür gibt es noch keine eigenen Bausteine, weil die bisherige Website keine hatte. Kurzfristig: Baustein **Text**
oder **Fragen & Antworten** auf der passenden Seite einfügen. Wenn Sie regelmässig Preise oder Termine pflegen
wollen, lassen Sie sich einen eigenen Baustein einbauen (kleiner Auftrag).

## Neue Seite anlegen

1. **Seiten** → «+» → Seitentitel eingeben, bei «Adresse (Slug)» auf **Generate** klicken.
2. Bausteine hinzufügen («+ Add item»): Hero, Text, Werkstätten, Bild, Text neben Bild, Aufruf, Kontaktformular, Fragen & Antworten.
   Reihenfolge per Ziehen am Griff links ändern.
3. Veröffentlichen. Damit die Seite im Menü erscheint: **Website-Einstellungen** → Hauptnavigation → Eintrag hinzufügen.

## Menü und Fusszeile

**Website-Einstellungen** → «Navigation & Fusszeile». Höchstens fünf Menüpunkte, sonst wird es auf dem Handy eng.

## Wenn etwas schiefging

- Jede Seite hat oben rechts eine **Historie** (Uhr-Symbol) – dort können Sie einen früheren Stand wiederherstellen.
- Nichts kann kaputtgehen, das nicht mit zwei Klicks zurückgeht. Das Layout selbst ist nicht veränderbar.

## Cookie-Hinweis, Impressum, Datenschutz

- **Cookie-Hinweis:** Website-Einstellungen → «Cookie-Hinweis» – Text und Schaltfläche ändern oder ganz ausschalten.
- **Impressum / Datenschutz:** Bereich Seiten → «Impressum» bzw. «Datenschutz» → Baustein «Text» bearbeiten. Beide sind in der Fusszeile verlinkt. Vor dem Go-live rechtlich prüfen lassen; das Impressum braucht noch UID/Handelsregister-Nummer.

## Vor dem Umzug auf garageklausner.ch

**Website-Einstellungen** → Suchmaschinen → «Demo-Modus» **ausschalten**, sonst bleibt die Website für Google unsichtbar.
